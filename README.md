# HumanOS

Plataforma de RRHH self-service para ICONSA (construcción Panamá). Digitaliza los formularios papel de RRHH; coexiste con MovimientOS en la misma BD Supabase.

**Stack:** Next.js 16 + TypeScript + Tailwind 4 + Supabase + Vercel.

**Estado de despliegue:** dev mirror en `jecg2804/HumanOS`. **Aún NO desplegado** — el home del MVP será `ICONSA-Solutions/HumanOS` (el Vercel `human-os` actual sirve el demo viejo). Ver `docs/STATUS.md`.

## Punteros

- **`CLAUDE.md`** — contrato del agente (reglas non-negotiable, stack, mental model, workflow).
- **`AGENTS.md`** — entry para agentes (Codex y otros).
- **`docs/STATUS.md`** — estado vivo (fase, decisiones, blockers, backlog). El único doc mutable de "qué falta".
- **`docs/`** — referencia topical (`reference/`), ADRs (`adr/`), CONTEXT, CHANGELOG.
